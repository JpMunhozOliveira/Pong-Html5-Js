A browser-based Pong clone built with HTML5 Canvas, CSS, and JavaScript. Play against a computer-controlled paddle in this classic arcade game.

![Pong gameplay](PongGif.gif)

## Features

- Player paddle controlled with mouse movement
- Computer-controlled opponent
- Ball and paddle collision detection
- Score tracking for both sides
- Ball speed increases after paddle hits
- Sound effects for paddle hits, wall bounces, and scoring

## How to Play

Move the mouse vertically over the game canvas to control your paddle. Return the ball past the opponent's paddle to score.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/JpMunhozOliveira/Pong-Html5-Js.git
   ```
2. Open `Pong/index.html` in a web browser.

No additional dependencies or build steps are required.
